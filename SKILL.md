# Founder board

1. Use the user’s idea and existing `founder/idea.md`. If missing, write it from the brief: product, buyer, price, channel, budget and constraints. Mark unknowns; ask only when they change the review.
2. Read [the three lenses](lenses.md): Offers, Monopoly and Product. These summarize published frameworks. Use lens names; never impersonate the authors or claim their endorsement.
3. Write `founder/board/brief.md` with facts and unknowns, without your verdict. For delegation, read your agent runtime's delegation guidance. Give one reviewer per lens the brief, lens file and output path. Respect available slots; do not assume shared chat history.
4. Each reviewer writes `founder/board/<lens>.md`: score 1–10; FUND / FUND IF / PASS; strengths; three main risks; questions; funding conditions. If delegation is unavailable, review each lens sequentially and label it a single-assistant review.
5. Read all memos. Write `founder/board.md`: vote and average score, shared risks, merged conditions, disagreements, open evidence gaps, and strongest viable version of the idea. Score the business, not the person. Unknown market/cost facts stay unknown.

Done: the brief, memos and summary exist and agree on scores/votes. Report the vote and next useful step. Run only the requested review; the other Founder skills are optional next steps.
